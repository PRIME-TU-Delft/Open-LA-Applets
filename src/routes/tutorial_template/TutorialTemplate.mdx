# Tutorial Template

The template system lets you build applets by editing one array (`appletObjects`) instead of writing custom Svelte rendering logic.

## Template applet structure

This is the complete page component for the 2D template applet (`src/routes/applet/calculus/template/template_applet/+page.svelte`):

```html
<script lang="ts">
  // imports, definitons...

  // ###############
  // CAMERA SETTINGS
  // ###############
  // choose one or none of the options below - if both are specified, view box will be used

  // (remove if unnecessary)
  cameraPosition = new Vector2(3, 1);
  cameraZoom = 1.5;

  // (remove if unnecessary)
  initialViewBox = new ViewBox(
    new Vector2(-3, -4), // bottom-left
    new Vector2(4, 7), // top-right
    0.5 // margin
  );

  // ####
  // AXIS
  // ####
  // here are the default settings for axis, you can change them

  // (remove if unnecessary)
  axis = {
    showOrigin: true,
    showAxisNumbersX: true,
    showAxisNumbersY: true,
    logarithmicX: false,
    logarithmicY: false,
    skipX: 0,
    skipY: 0
  };

  // #####
  // SCALE
  // #####
  // All child components (functions, points, lines, etc.) will auto-scale accordingly.
  // Example: scaleX={2} means 1 world (mathematical) unit = 2 SVG (screen) units on the x-axis.
  // Formulas and positions should be written in world (mathematical) space.
  let scaleX = 1;
  let scaleY = 1;

  // ###########
  // AXIS LABELS
  // ###########

  // (remove if unnecessary)
  xAxisLabel = '';
  yAxisLabel = '';

  // ##############
  // APPLET OBJECTS
  // ##############
  const appletObjects: AppletObject[] = [
    new FunctionFragment((x: number) => x ** 2 - 2, PrimeColor.raspberry, { domain: { xMin: -1, xMax: 2.14 } }),
    new FunctionFragment('\\frac{{x+1}^2}{x+1}', PrimeColor.blue, { domain: { xMax: 3 }, isDashed: false, shape: 'square', legendText: 'f(x)' })
      .addGaps(new Vector2(-1, 0))
      .addIncludedPoints(new Vector2(3, 4)),
    new FunctionFragment('e^x', PrimeColor.darkGreen, { integral: { xLeft: -4, xRight: -1.25, isDashed: false }, legendText: 'g(x)' }),
    new AsymptoteFragment(2, 'vertical', PrimeColor.cyan),
    new AsymptoteFragment(-1.5, 'horizontal', PrimeColor.black),
    new ObliqueAsymptoteFragment('x+2', PrimeColor.orange)
  ];
</script>

<Canvas2D
  {initialViewBox}
  {cameraPosition}
  {cameraZoom}
  legendItems={getLegend(appletObjects)}
  labels={{ xLabel: xAxisLabel ?? undefined, yLabel: yAxisLabel ?? undefined }}
  {axis}
  {scaleX}
  {scaleY}
>
  <TemplateComponent objects={appletObjects} />
</Canvas2D>
```

In practice, you should usually edit only `appletObjects`. Everything in this array is rendered automatically by `TemplateComponent`.
For 3D applets the same can be achieved by ediitng `appletObjects` and everything in the array is rendered automatically by `TemplateComponent3D`.

If you want a custom starting camera, define a `ViewBox` in the `camera settings` part, or set `cameraPosition` and `cameraZoom`. If not, then remove the `camera settings` lines.

For the 2D case:

```ts
const appletObjects: AppletObject[] = [
  // Your objects here
];
```

For the 3D case:

```ts
const appletObjects: AppletObject3D[] = [
  // Your objects here
];
```

## Optional: set an initial view

### Using a `ViewBox` (2D)

Use `ViewBox` when you want to guarantee a minimum visible area on first render, independent of viewport size.

```ts
initialViewBox = new ViewBox(
  new Vector2(-3, -4), // bottom-left
  new Vector2(4, 7), // top-right
  0.5 // optional margin
);
```

Notes:

- `initialViewBox` is only used for the initial camera state.
- Users can still pan and zoom normally afterwards.
- On wide screens users may see more than the box; the box defines the minimum area that should be visible.
- View box cannot be used together with `cameraPosition` or `cameraZoom`.

### Using `cameraPosition` and `cameraZoom`

If you only want to set camera position and zoom, you can use `cameraPosition` and `cameraZoom` properties in the camera settings section.

2D case:

```ts
cameraPosition = new Vector2(3, 1);
cameraZoom = 1.5;
```

3D case:

```ts
cameraPosition = new MathVector3(10, 10, 10);
cameraZoom = 29;
```

Notes:

- (2D): Those properties cannot be used together with `ViewBox`, you need to remove its definition if you want to use this method.

## Optional: configure axis

You can configure axis display by setting the `axis` object.

2D case:

```ts
axis = {
  showOrigin: true,
  showAxisNumbersX: true,
  showAxisNumbersY: true,
  logarithmicX: false,
  logarithmicY: false,
  skipX: 0,
  skipY: 0
};
```

What each option does:

- `showOrigin`: show or hide the origin marker.
- `showAxisNumbers`: show or hide axis tick labels.
- `logarithmicX`: use logarithmic scaling on x-axis.
- `logarithmicY`: use logarithmic scaling on y-axis.
- `skipX`: skip every n-th x-axis label/tick according to axis renderer settings.
- `skipY`: skip every n-th y-axis label/tick according to axis renderer settings.

3D case:

```ts
showAxes = true;
showNumbers = false;
hideTicks = true;
axisLength = 10;
axisSpacing = 2;
floor = false;
hideOrigin = false;
```

What each option does:

- `showAxes`: show or hide the axes.
- `showNumbers`: show or hide axis tick labels.
- `hideTicks`: show or hide axis ticks.
- `axislength`: specify length of axis.
- `axisSpacing`: specify the spacing between ticks.
- `floor`: show or hide floor.
- `hideOrigin`: show or hide the origin marker.

## Optional (2D): set scale

To change the coordinate system scale, pass `scaleX` and/or `scaleY` to `Canvas2D`:

```html
<Canvas2D scaleX={1.5} scaleY={3} {axis}>
  <TemplateComponent objects={appletObjects} />
</Canvas2D>
```

- `scaleX`: how many SVG (screen-space) units correspond to 1 world (mathematical) unit on the x-axis. Default: `1`.
- `scaleY`: how many SVG (screen-space) units correspond to 1 world (mathematical) unit on the y-axis. Default: `1`.

All child components (functions, points, lines, axis, etc.) automatically read the scale from context and adjust accordingly. This means:

- **Formulas** should be written in pure mathematical (world) space. For example, use `'\\cos(x)'` instead of manually pre-scaling like `'3\\cos(x/1.5)'`.
- **Domains and integral bounds** should be in world space. For example, `domain: { xMin: 0, xMax: 2 * Math.PI }` instead of `{ xMin: 0, xMax: 2 * Math.PI * scaleX }`.
- **Point positions** (gaps, included points) should be in world space.
- **Axis tick labels** automatically show world-space values.
- **`Latex2D` positions** are in world space. They automatically scale based on the active scale context.
- **`additionalTicksX`/`additionalTicksY`** values should be in world space. The Axis component automatically converts them to screen space internally.

## Optional: set axis labels

If you want to also have dynamic axis labels in your applet, you can define them in the `axis labels` part. They are rendered with LaTeX.

Example:

2D case:

```ts
// ###########
// AXIS LABELS
// ###########

xAxisLabel = 'x';
yAxisLabel = 'f(x)';
```

3D case:

```ts
// ###########
// AXIS LABELS
// ###########

x1 = 'x';
x2 = 'y';
x3 = 'f(x,y)'
```

## Template objects

### 2D case:

The `appletObjects` array can contain the following types of objects:

- `FunctionFragment`: a function graph (defined by JavaScript function or LaTeX string).
- `ImplicitFunctionFragment`: an implicit curve defined by `f(x, y) = 0` or by an equation string such as `'x^2 + y^2 = 4'`.
- `ParameterizedFunctionFragment`: a parametric curve defined by `x(t)` and `y(t)`.
- `AsymptoteFragment`: a vertical or horizontal dashed asymptote.
- `ObliqueAsymptoteFragment`: an oblique asymptote (defined by JavaScript function or LaTeX string).
- `Text`: a standalone LaTeX label.
- `Point`: a single point with optional shape and label.
- `LineFragment`: a finite line segment with optional label and (optional) manual label alignment.
- `Circle`: a circle, optionally with drawn radii and radius labels.
- `Angle`: an angle arc (or right-angle marker).
- `Polygon`: a polygon with optional fill, side labels, and vertex labels.

### 1) `FunctionFragment`

Constructor:

```ts
new FunctionFragment(func, color, options?)
```

- `func`: either `(x: number) => number` or a LaTeX string (for example `'\\sin(x)'`).
- `color`: one of the `PrimeColor` values.
- `options` (optional): an object with the following properties:
  - `domain`: `{ xMin?: number; xMax?: number }`, specifies where the function should be drawn. You can specify just `xMin`, just `xMax`, or both. Omit both to display across the entire view.
  - `isDashed`: `true` or (by default) `false`, renders the function with a dashed line instead of solid.
  - `shape`: `'circle'`, `'square'` or `'triangle'`, used for the points (gaps, included points) and legend item shapes. Default: `'circle'`.
  - `integral`: `{ xLeft: number; xRight: number; isDashed?: boolean; legendText?: string }` to shade area under the function between two x-values.
  - `legendText`: text to display in the legend for this function.

Useful chaining methods:

```ts
new FunctionFragment('\\frac{{x+1}^2}{x+1}', PrimeColor.blue, { domain: { xMax: 3 }, isDashed: true, legendText: 'f(x)' })
  .addGaps(new Vector2(-1, 0), "gaps")
  .addIncludedPoints(new Vector2(3, 4));
```

- `.addGaps(positions, legendText?)`: adds open circles at those coordinates. Pass an array of `Vector2` points for multiple gaps. The optional second parameter sets legend text for these points (e.g., `.addGaps([new Vector2(-1, 0), new Vector2(2, 1)], 'discontinuity')`)
- `.addIncludedPoints(positions, legendText?)`: adds filled circles/shapes at those coordinates. Also supports multiple points and optional legend text.

More `FunctionFragment` examples:

```ts
// 1) JavaScript function: polynomial
new FunctionFragment((x: number) => x ** 3 - 2 * x, PrimeColor.raspberry);

// 2) JavaScript function: trigonometric
new FunctionFragment((x: number) => Math.sin(2 * x), PrimeColor.blue, {
  domain: { xMin: -Math.PI, xMax: Math.PI }
});

// 3) JavaScript function: piecewise, using JS ternary operator
new FunctionFragment((x: number) => (x < 0 ? -1 : 1), PrimeColor.darkGreen, { domain: { xMin: -3, xMax: 3 } });

// 4) JavaScript function with an integral region
new FunctionFragment((x: number) => 0.5 * x + 1, PrimeColor.orange, {
  domain: { xMin: -2, xMax: 4 },
  integral: { xLeft: 0, xRight: 3, isDashed: true }
});

// 5) LaTeX string: trigonometric
new FunctionFragment('\\sin(2x)', PrimeColor.cyan, { domain: { xMin: -3.14, xMax: 3.14 } });

// 6) Function with square points and legend text
new FunctionFragment((x: number) => -x, PrimeColor.raspberry, {
  shape: 'square',
  legendText: 'Some function f(x)'
});

// 7) Function with only legend defined
new FunctionFragment((x: number) => x ** 2 - 3, PrimeColor.raspberry, {
  legendText: 'Another function g(x)'
});

// 8) Complex function with multiple gaps, points, and integral
new FunctionFragment('\\frac{1}{x^2 - 4}', PrimeColor.blue, {
  domain: { xMin: -5, xMax: 5 },
  integral: { xLeft: 0.5, xRight: 1.9, isDashed: true, legendText: 'area₁' }
})
  .addGaps(new Vector2(-2, 0), 'vertical asymptotes')
  .addGaps(new Vector2(2, 0))
  .addIncludedPoints(new Vector2(0, -0.25), 'y-intercept');

// 9) Dashed function with multiple integral regions for comparison
new FunctionFragment((x: number) => x ** 2 - 1, PrimeColor.orange, {
  isDashed: true,
  shape: 'square',
  integral: { xLeft: -2, xRight: 0, isDashed: false, legendText: 'solid area' }
})
  .addIncludedPoints([new Vector2(-1, 0), new Vector2(1, 0)], 'zeros');
```

Use JavaScript functions when you want logic (for example piecewise behavior), and use LaTeX strings when you want concise math notation.

### 2) `ImplicitFunctionFragment`

Constructor:

```ts
new ImplicitFunctionFragment(func, color, options?)
```

- `func`: either `(x: number, y: number) => number` or a LaTeX string.
- For LaTeX strings, you can pass either a zero-form expression (for example `'x^2 + y^2 - 4'`) or an equation (for example `'x^2 + y^2 = 4'`).
- `color`: one of the `PrimeColor` values.
- `options` (optional):
  - `domain`: `{ xMin?: number; xMax?: number }`, limits x-range used during rendering.
  - `range`: `{ yMin?: number; yMax?: number }`, limits y-range used during rendering.
  - `isDashed`: `true` or (by default) `false`.
  - `shape`: `'circle'`, `'square'` or `'triangle'`, used for legend and points.
  - `legendText`: text to display in the legend.

Examples:

```ts
// Implicit circle
new ImplicitFunctionFragment('x^2 + y^2 = 4', PrimeColor.darkGreen, {
  legendText: 'x^2 + y^2 = 4'
});

// Implicit hyperbola from JS function
new ImplicitFunctionFragment((x: number, y: number) => x * x - y * y - 1, PrimeColor.blue, {
  domain: { xMin: -3, xMax: 3 },
  isDashed: true
});
```

### 3) `ParameterizedFunctionFragment`

Constructor:

```ts
new ParameterizedFunctionFragment(xFunc, yFunc, color, options?)
```

- `xFunc`: either `(t: number) => number` or a LaTeX string for $x(t)$.
- `yFunc`: either `(t: number) => number` or a LaTeX string for $y(t)$.
- `color`: one of the `PrimeColor` values.
- `options` (optional):
  - `tStart`: start value for parameter `t`.
  - `tEnd`: end value for parameter `t`.
  - `isDashed`: `true` or (by default) `false`.
  - `shape`: `'circle'`, `'square'` or `'triangle'`.
  - `legendText`: text to display in the legend.

Examples:

```ts
// Unit circle, traversed once
new ParameterizedFunctionFragment('cos(t)', 'sin(t)', PrimeColor.orange, {
  tStart: 0,
  tEnd: 2 * Math.PI,
  legendText: 'unit circle'
});

// Spiral from JS functions
new ParameterizedFunctionFragment(
  (t: number) => t * Math.cos(t),
  (t: number) => t * Math.sin(t),
  PrimeColor.raspberry,
  { tStart: 0, tEnd: 4 * Math.PI }
);
```

### 4) `AsymptoteFragment`

Constructor:

```ts
new AsymptoteFragment(position, type, color);
```

- `position`: x-value (vertical) or y-value (horizontal)
- `type`: `'vertical'` or `'horizontal'`
- `color`: one of the `PrimeColor` values

Examples:

```ts
new AsymptoteFragment(1, 'vertical', PrimeColor.cyan);
new AsymptoteFragment(-2, 'horizontal', PrimeColor.black);
```

### 5) `ObliqueAsymptoteFragment`

Constructor:

```ts
new ObliqueAsymptoteFragment(func, color, legendText);
```

- `func`: either `(x: number) => number` or a LaTeX string (for example `'x+2'`)
- `color`: one of the `PrimeColor` values
- `legendText`: (optional) text to display in the legend for this asymptote

Example:

```ts
new ObliqueAsymptoteFragment('x+2', PrimeColor.orange, "asymptote");
new ObliqueAsymptoteFragment('-x', PrimeColor.raspberry);
```

### 6) `Text`

Constructor:

```ts
new Text(latex, position, color, alignment?);
```

- `latex`: LaTeX string to display.
- `position`: `Vector2` position.
- `color`: one of the `PrimeColor` values.
- `alignment` (optional): `{ alignX?: 'left' | 'right' | 'center'; alignY?: 'top' | 'bottom' | 'center' }`.

Examples:

```ts
new Text('x_0', new Vector2(1.2, -0.5), PrimeColor.black);
new Text('A', new Vector2(-2, 3), PrimeColor.blue, { alignX: 'right', alignY: 'bottom' });
```

### 7) `Point`

Constructor:

```ts
new Point(position, color, options?);
```

- `position`: `Vector2` position.
- `color`: one of the `PrimeColor` values.
- `options` (optional):
  - `shape`: `'circle' | 'square' | 'triangle'`
  - `latex`: optional point label
  - `legendText`: optional legend text

Examples:

```ts
new Point(new Vector2(1, 2), PrimeColor.orange);
new Point(new Vector2(-1, 0), PrimeColor.raspberry, { shape: 'square', latex: 'P' });
```

### 8) `LineFragment`

Constructor:

```ts
new LineFragment(start, end, color, options?);
```

- `start`, `end`: `Vector2` endpoints.
- `color`: one of the `PrimeColor` values.
- `options` (optional):
  - `latex`: label near the midpoint
  - `isDashed`: dashed segment
  - `latexAlign`: optional manual alignment override

Automatic label behavior:

- If `latexAlign` is not provided, alignment is chosen from the midpoint direction (left/right and top/bottom).
- For near-vertical lines, an extra small horizontal offset is automatically added so the label does not sit on the line.
- If you provide `latexAlign.alignX` and/or `latexAlign.alignY`, your provided values override auto-alignment for those axes.

Examples:

```ts
new LineFragment(new Vector2(-2, -1), new Vector2(2, 1), PrimeColor.darkGreen, {
  latex: 'd'
});

new LineFragment(new Vector2(1, -2), new Vector2(1, 2), PrimeColor.blue, {
  latex: 'x=1',
  latexAlign: { alignX: 'left', alignY: 'center' }
});
```

### 9) `Circle`

Constructor:

```ts
new Circle(origin, radius, color, options?);
```

- `origin`: `Vector2` center.
- `radius`: radius value.
- `color`: one of the `PrimeColor` values.
- `options` (optional):
  - `isDashed`: dashed circle
  - `radiiShown`: list of angles (in radians) where radius segments are drawn
  - `radiusLatex`: label drawn for each shown radius

Example:

```ts
new Circle(new Vector2(0, 0), 2, PrimeColor.cyan, {
  radiiShown: [0, Math.PI / 2, Math.PI],
  radiusLatex: 'r'
});
```

### 10) `Angle`

Constructor:

```ts
new Angle(position, startAngle, endAngle, color, options?);
```

- `position`: origin point (`Vector2`).
- `startAngle`, `endAngle`: radians.
- `color`: one of the `PrimeColor` values.
- `options` (optional):
  - `hasHead`: draw arrow head on arc
  - `distance`: distance of arc from origin
  - `latex`: LaTeX label shown near the angle arc

Alternative constructor:

```ts
Angle.fromVectors(position, v1, v2, color, options?)
```

Example:

```ts
new Angle(new Vector2(0, 0), 0, Math.PI / 3, PrimeColor.orange, {
  hasHead: true,
  latex: '\\alpha'
});
```

Using `fromVectors` with a label:

```ts
Angle.fromVectors(
  new Vector2(0, 0),
  new Vector2(1, 0),
  new Vector2(1, 1),
  PrimeColor.blue,
  { latex: '\\theta' }
);
```

### 11) `Polygon`

Constructor:

```ts
new Polygon(points, color, options?);
```

- `points`: `Vector2[]` in clockwise or anti-clockwise order.
- `color`: one of the `PrimeColor` values.
- `options` (optional):
  - `fillStyle`: `'full' | 'dashed' | 'none'`
  - `sideLatex`: labels for polygon sides (in edge order)
  - `verticesLatex`: labels for polygon vertices (in point order)

Automatic side-label behavior:

- Side labels are auto-aligned from each side midpoint direction.
- For near-vertical sides, a small horizontal offset is added automatically to avoid overlap with the side.

Automatic vertex-label behavior:

- Vertex labels are auto-aligned using the vector from polygon center to the vertex.
- Labels are nudged slightly outward along that same center-to-vertex direction.

Example:

```ts
new Polygon(
  [new Vector2(-2, -1), new Vector2(0, 2), new Vector2(2, -1)],
  PrimeColor.raspberry,
  {
    fillStyle: 'none',
    sideLatex: ['a', 'b', 'c'],
    verticesLatex: ['A', 'B', 'C']
  }
);
```

### 3D case:

The `appletObjects` array can contain the following types of objects:

- `SurfaceFunction3D`: a function graph (defined by JavaScript function or LaTeX string).
- `TextObject3D`: a standalone LaTeX label.
- `VectorFieldObject3D`: a vector field (defined by a JavaScript function).
- `PointObject3D`: a single point with optional shape and label.
- `LineSegmentObject3D`: a finite line segment with optional label and (optional) manual label alignment.
- `InfiniteLineObject3D`: an infinite line segment with optional label and (optional) manual label alignment.
- `AngleObject3D`: an angle arc (or right-angle marker).
- `PolygonObject3D`: a polygon with optional fill, side labels, and vertex labels.
- `CuboidObject3D`: a cuboid with optional edges outlined.
- `CurveObject3D`: a curve defined by an x, y, and z JavaScript function.

### 1) `SurfaceFunction3D`

Constructor:

```ts
new SurfaceFunction3D(func, color, options?);
```

- `func`: either `(x: number, y:number) => number` or a LaTeX string (for example `'\\sin(x)'+'\\sin(y)'`).
- `color`: one of the `PrimeColor` values.
- `options` (optional): an object with the following properties:
  - `xRange`: `[number, number]`, specifies for which x-values the function should be drawn. You can specify just min, max, or both. Omit both to display across the entire view.
  - `yRange`: `[number, number]`, specifies for which y-values the function should be drawn. You can specify just min, max, or both. Omit both to display across the entire view.
  - `shape`: `'circle'`, `'square'` or `'triangle'`, used for legend item shapes. Default: `'circle'`.
  - `legendText`: text to display in the legend for this function.
  - `opacity`: `number` the level of opacity the function should take.
  - `wireframe`: `boolean` whether or not the function is visualized as solid or wireframe

`SurfaceFunction3D` examples:

```ts
// 1) JavaScript function: polynomial
new SurfaceFunction3D((x, y) => x * x + y * y + 3, PrimeColor.raspberry, {
      wireframe: true,
      shape: 'square',
      legendText: 'Surface'
    });

// 2) JavaScript function: trigonometric
new SurfaceFunction3D((x, y) => Math.sin(x) - Math.cos(y), PrimeColor.blue, {
      shape: 'square',
      legendText: 'Surface'
    });
```

### 2) `TextObject3D`

Constructor:

```ts
new TextObject3D(latex, position, color, size);
```

- `latex`: LaTeX string to display.
- `position`: `Vector3` position.
- `color`: one of the `PrimeColor` values.
- `size`: `number` the fontsize of the text.

Examples:

```ts
new TextObject3D('f(x)=\\frac{x-1}{x+3+y}', new MathVector3(0, 6, 8), PrimeColor.darkGreen);
new TextObject3D('\\pi', new MathVector3(0, 0, -2), PrimeColor.blue, 6);
```

### 3) `VectorFieldObject3D`

Constructor:

```ts
new VectorFieldObject3D(func, color, options?);
```

- `func`: `(x: number, y: number, z: number) => Vector3` function defining the vector field.
- `options` (optional): an object with the following properties:
  - `xRange`: `[number, number]` range of x values the vector field is rendered for.
  - `yRange`: `[number, number]` range of y values the vector field is rendered for.
  - `zRange`: `[number, number]` range of z values the vector field is rendered for.
  - `step`: `number` step taken for vectors rendered in the vector field.
  - `normalize`: `boolean` whether vectors are normalized.
  - `normalizedLength`: `number` the length for normalized vectors.
  - `hideHead`: `boolean` whether the head of the vectors in the vector field are rendered.
  - `anchor`: `'middle' | 'start' | 'end'` specifies anchor point for vectors.
  - `color`: one of the `PrimeColor` values.
  - `colorFn`: `(x: number, y: number) => PrimeColor | string` function mapping the location of the vectors to a color.

Example:

```ts
new VectorFieldObject3D((x: number, y: number) => new MathVector3(x, -y, 0), {
      xRange: [-2, 2],
      yRange: [-2, 2],
      zRange: [-2, 2],
      step: 0.5,
      colorFn: (x: number, y: number, z: number) =>
        x * y * z >= 0 ? PrimeColor.blue : PrimeColor.raspberry
    });
```

### 4) `PointObject3D`

Constructor:

```ts
new PointObject3D(position, color, options);
```

- `position`: `Vector3` position of the point object in 3D space.
- `color`: one of the `PrimeColor` values.

## Step-by-step: create an example applet

In this section, we build a small 2D applet from scratch using only `appletObjects`.

### Step 1: Start with one function

Create a parabola on a limited domain:

```ts
const appletObjects: AppletObject[] = [
  new FunctionFragment((x: number) => x ** 2 - 1, PrimeColor.raspberry, { domain: { xMin: -2, xMax: 2 } })
];
```

### Step 2: Add a removable discontinuity

Now add a rational function, an open circle at the gap, and a filled value at another point. You can chain multiple `.addGaps()` and `.addIncludedPoints()` calls:

```ts
const appletObjects: AppletObject[] = [
  new FunctionFragment((x: number) => x ** 2 - 1, PrimeColor.raspberry, { domain: { xMin: -2, xMax: 2 } }),
  new FunctionFragment('\\frac{{x+1}^2}{x+1}', PrimeColor.blue, { domain: { xMin: -3, xMax: 3 } })
    .addGaps(new Vector2(-1, 0), 'hole at x = -1')
    .addIncludedPoints(new Vector2(2, 3))
];
```

### Step 3: Add an integral region

Add a third function and shade its integral between two x-values. You can use `isDashed: true` for a hatched fill pattern:

```ts
const appletObjects: AppletObject[] = [
  new FunctionFragment((x: number) => x ** 2 - 1, PrimeColor.raspberry, { domain: { xMin: -2, xMax: 2 } }),
  new FunctionFragment('\\frac{{x+1}^2}{x+1}', PrimeColor.blue, { domain: { xMin: -3, xMax: 3 } })
    .addGaps(new Vector2(-1, 0), 'hole at x = -1')
    .addIncludedPoints(new Vector2(2, 3)),
  new FunctionFragment('e^x', PrimeColor.darkGreen, {
    integral: { xLeft: -2, xRight: 0, isDashed: false, legendText: 'area under curve' }
  })
];
```

### Step 4: Add asymptotes

Finally, add vertical/horizontal asymptotes and one oblique asymptote. Oblique asymptotes can include legend text:

```ts
const appletObjects: AppletObject[] = [
  new FunctionFragment((x: number) => x ** 2 - 1, PrimeColor.raspberry, { domain: { xMin: -2, xMax: 2 } }),
  new FunctionFragment('\\frac{{x+1}^2}{x+1}', PrimeColor.blue, { domain: { xMin: -3, xMax: 3 } })
    .addGaps(new Vector2(-1, 0), 'hole at x = -1')
    .addIncludedPoints(new Vector2(2, 3)),
  new FunctionFragment('e^x', PrimeColor.darkGreen, {
    integral: { xLeft: -2, xRight: 0, isDashed: false, legendText: 'area under curve' }
  }),
  new AsymptoteFragment(1, 'vertical', PrimeColor.cyan),
  new AsymptoteFragment(-2, 'horizontal', PrimeColor.black),
  new ObliqueAsymptoteFragment('x+2', PrimeColor.orange, 'oblique asymptote')
];
```

## How to create your own template applet

1. **Copy the template applet** and keep the structure.

2. **Edit only `appletObjects`** — Add objects that represent your mathematical content.

3. **Combine features freely** — You can mix and match:
   - Function domains (partial or full)
   - Dashing styles
   - Point shapes (circle, square, triangle)
   - Integral fills (solid or hatched)
   - Custom legend labels for everything
   - Multiple gaps and included points via chaining

4. **Set camera framing (optional)** — 2D: Use `initialViewBox` for guaranteed minimum visible area, or `cameraPosition`/`cameraZoom` for simple positioning.

5. **Next steps** — If your applet needs interactivity or custom logic, ask a TA for help.
